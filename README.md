# E-Commerce Website Automation Testing

## Project Overview
This project automates the end-to-end testing of an e-commerce website using Selenium WebDriver, Java, Maven, and TestNG.

Application: https://www.saucedemo.com/

## Tools & Technologies
- Java
- Selenium WebDriver
- Maven
- TestNG
- Eclipse IDE
- Git & GitHub

## Project Features
- Login Testing
- Product Page Testing
- Add to Cart Testing
- Remove Product Testing
- Checkout Testing
- End-to-End Purchase Testing
- Screenshot Capture on Test Failure
- Page Object Model (POM)

## Project Structure
```text
src/main/java
  com.ecommerce.base
  com.ecommerce.pages
  com.ecommerce.utils

src/test/java
  com.ecommerce.tests

pom.xml
testng.xml
README.md
```

## How to Run the Project

1. Clone the repository.
2. Import the project into Eclipse as an Existing Maven Project.
3. Update Maven dependencies.
4. Run `testng.xml` as a TestNG Suite.
